UploadEz
Quellcode

Selbst gehostet · LAMP · PHP 8

Dateien teilen,
ohne sie wegzugeben.

UploadEz läuft auf deinem eigenen Server. Dateien bis 2 GB, ein Link mit Ablaufdatum, auf Wunsch passwortgeschützt. Kein fremder Anbieter zwischen dir und deinen Daten.

Auf GitHub ansehen Selbst einrichten

Was es kann

Sechs Dinge, die zählen

Große Dateien

Bis 2 GB. Der Browser zerlegt sie in 5-MB-Stücke und schickt sie einzeln. Bricht eine Verbindung ab, läuft nur das Stück neu, nicht die ganze Datei.

Passwort pro Link

Wer den Link hat, kommt trotzdem nicht rein. Das Passwort wird als bcrypt-Hash gespeichert, nicht im Klartext.

Links laufen ab

Nach sieben Tagen ist Schluss, einstellbar. Ein Cronjob räumt Datei und Datenbankeintrag zusammen weg — nicht nur den Eintrag.

Geprüfte Dateitypen

Der Server sieht sich die fertige Datei selbst an, statt dem Browser zu glauben. Erkannter Typ und Dateiendung müssen zusammenpassen.

Bremse gegen Missbrauch

Pro IP-Adresse ein Limit im Zeitfenster. Die Zählung läuft in einer Datenbanktransaktion, damit gleichzeitige Anfragen nicht durchrutschen.

Übersicht für dich

Ein passwortgeschützter Bereich zeigt alle Uploads mit Größe, Status, Zahl der Downloads und Ablauf. Löschen inklusive.

Wie es läuft

Drei Schritte

1

Datei wählen

Hineinziehen oder klicken. Größe und Endung werden sofort geprüft.

2

Hochladen

Fortschritt, Geschwindigkeit und verbleibende Zeit stehen daneben.

3

Link teilen

Kopieren oder direkt per E-Mail verschicken. Fertig.

Voraussetzungen

Was der Server braucht

PHP8.0 oder neuer, mit fileinfo
DatenbankMySQL 5.7+ oder MariaDB 10.3+
WebserverApache 2.4+ mit mod_rewrite und mod_headers
PHP-Limitsupload_max_filesize und post_max_size auf 2G
OptionalComposer für PHPMailer — sonst greift mail()
EinrichtungRepository klonen, .env ausfüllen, schema.sql einspielen

Diese Seite ist nur die Beschreibung. UploadEz braucht PHP und eine Datenbank und kann darum nicht auf GitHub Pages laufen. Die Anwendung selbst gehört auf deinen eigenen Server — die Schritte dafür stehen in der README.md im Repository.
